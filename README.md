# ระบบขอใบอนุญาตออนไลน์ — อบต.เชิงทะเล (เวอร์ชันปรับปรุง)

โครงสร้างเดิมเหมือนเดิมทุกอย่าง (Cloudflare Pages + Functions + D1) แค่แทนที่ไฟล์ใน repo แล้ว push ขึ้น GitHub

## วิธีติดตั้ง (3 ขั้นตอน)

1. **แทนที่ไฟล์ใน GitHub repo** `saosuk-permit-app` ด้วยไฟล์ในโฟลเดอร์นี้ทั้งหมด
   (ลบไฟล์เก่าใน `functions/api/` และ `public/` ที่ไม่มีในชุดนี้ออกด้วย แล้ว commit) — Cloudflare จะ deploy ให้อัตโนมัติ
2. **ตั้งรหัสผ่านเจ้าหน้าที่ (สำคัญมาก)**
   Cloudflare Dashboard → Workers & Pages → `saosuk-permit-app` → **Settings → Variables and Secrets → Add**
   - ชื่อ `ADMIN_PASSWORD`  ค่า = รหัสผ่านที่ต้องการ (ควรยาว 10 ตัวอักษรขึ้นไป) ชนิด **Secret**
   - (ทางเลือก) ชื่อ `SESSION_SECRET` ค่า = ข้อความสุ่มยาว ๆ
   จากนั้นกด **Deployments → Retry/Redeploy** 1 ครั้งเพื่อให้ตัวแปรมีผล
3. เปิด `https://saosuk-permit-app.pages.dev/admin.html` แล้วเข้าสู่ระบบ

> **ฐานข้อมูล:** ไม่ต้องรัน SQL เอง ระบบจะเพิ่มคอลัมน์/ตารางใหม่ให้อัตโนมัติเมื่อมีคนเรียกใช้ครั้งแรก
> และข้อมูลคำขอเดิมทั้งหมดยังอยู่ครบ (ใบอนุญาตที่อนุมัติไปแล้วจะได้เลขเดิม/วันหมดอายุ 31 ธ.ค. 2569 ตามที่เคยพิมพ์)

## แก้ไขข้อความ/ข้อมูลหน่วยงาน
แก้ที่ไฟล์เดียว `public/assets/config.js` — ชื่อหน่วยงาน เบอร์โทร อีเมล เวลาทำการ ผู้ลงนาม ประเภทกิจการ

## การอัปโหลดไฟล์เอกสาร
ผู้ยื่นอัปโหลดไฟล์ (JPG / PNG / PDF ไม่เกิน 5 MB, สูงสุด 5 ไฟล์) ได้ทันที **ไม่ต้องตั้งค่าอะไรเพิ่ม** — ไฟล์เก็บในฐานข้อมูล D1 เดิม
- รูปถ่ายจากมือถือจะถูกย่อให้เล็กลงอัตโนมัติก่อนส่ง (ภาพ 9 MB → ราว 1 MB) ไฟล์ PDF ส่งตามจริง
- เจ้าหน้าที่เปิดดูไฟล์ได้ในหน้ารายละเอียดคำขอ (เฉพาะผู้ที่ล็อกอินเท่านั้น) และผู้ยื่นแนบไฟล์เพิ่มเองได้เมื่อถูกขอให้แก้ไขเอกสาร
- ยังแนบลิงก์ Google Drive เพิ่มได้เหมือนเดิม (ไม่บังคับ)
- จำกัดการอัปโหลดไม่เกิน 100 ไฟล์/ชั่วโมง/IP และลบไฟล์ที่อัปโหลดแล้วไม่ได้ผูกกับคำขอเกิน 2 วันให้อัตโนมัติ
- **ถ้าปริมาณไฟล์มากขึ้นในอนาคต** (D1 ฟรีมีพื้นที่รวม 5 GB) ให้สร้าง R2 bucket ชื่อ `saosuk-permit-docs` แล้วลบ `#` หน้าบล็อก `[[r2_buckets]]` ใน `wrangler.toml` ไฟล์ใหม่จะไปเก็บที่ R2 เอง ส่วนไฟล์เก่ายังเปิดดูได้ตามปกติ

## สิ่งที่แก้ไข/เพิ่ม

**ความปลอดภัย (ของเดิมมีช่องโหว่ร้ายแรง)**
- เดิมใครก็เปิด `/api/admin-list` ได้และเห็นเลขบัตรประชาชนของทุกคน, สั่งอนุมัติผ่าน `/api/update-status` ได้โดยไม่ล็อกอิน → ตอนนี้ต้องล็อกอินเจ้าหน้าที่ (คุกกี้ HttpOnly, หมดอายุ 12 ชม., ล็อกชั่วคราวถ้าใส่รหัสผิดเกิน 8 ครั้ง)
- หน้าติดตามสถานะเดิมค้นด้วย `LIKE %…%` พิมพ์ "0" ก็ได้ข้อมูลคนอื่นทั้งหมด → ตอนนี้ต้องตรงทั้งหมดเท่านั้น และปิดบังนามสกุลบางส่วน
- กัน XSS (เดิมเอาข้อความผู้ใช้ใส่ HTML ตรง ๆ), กัน CSRF, ตรวจข้อมูลฝั่งเซิร์ฟเวอร์ทุกช่อง (เลขบัตรตรวจ checksum จริง, เบอร์โทร, URL ต้องเป็น http/https)
- กัน CSV injection, กันบอท (honeypot), กันยื่นซ้ำ

**ฟังก์ชันที่แก้**
- เลขคำขอเดิมสุ่ม 4 หลักอาจซ้ำ → ตอนนี้รันตามลำดับ `REQ-2569-00001`
- เลขใบอนุญาตเดิมสร้างจากเลขคำขอ → ตอนนี้ออกอัตโนมัติเมื่ออนุมัติ `สส. 2569/0001` (ต่ออายุใช้เลขเดิม)
- วันออก/วันหมดอายุเก็บจริงในฐานข้อมูล ปรับวันหมดอายุได้ตอนอนุมัติ (เดิมฟิกซ์ 31 ธ.ค. 2569 ในหน้าพิมพ์)
- ใบอนุญาตเดิมไม่มีที่อยู่ผู้ขอ (ใช้ที่อยู่ร้านแทน) → เพิ่มช่องที่อยู่ผู้ขอ
- QR Code บนใบอนุญาตเดิมเป็นแค่กล่องเปล่า → ตอนนี้เป็น QR จริงชี้ไปหน้าตรวจสอบ

**ฟีเจอร์ใหม่**
- ฟอร์มยื่นคำขอ 3 ขั้นตอน ตรวจข้อมูลทันที หน้าสรุปก่อนส่ง ยินยอม PDPA
- อัปโหลดไฟล์เอกสารได้โดยตรง (ย่อรูปอัตโนมัติ) และ ผู้ยื่น "ส่งเอกสารแก้ไข" เองได้เมื่อเจ้าหน้าที่ให้แก้ (ยืนยันด้วยเบอร์โทร)
- ไทม์ไลน์ประวัติการดำเนินการ, หน้า **ตรวจสอบใบอนุญาต** สาธารณะ (`verify.html`)
- แดชบอร์ดเจ้าหน้าที่: สถิติ, กราฟ 14 วัน, ค้นหา/กรอง/เรียง, แบ่งหน้า, แจ้งเตือนคำขอที่รอนาน และใบอนุญาตใกล้หมดอายุ, ส่งออก CSV, ลิ้นชักรายละเอียด, ข้อความสำเร็จรูป, เปิดแผนที่
- รองรับมือถือเต็มรูปแบบ, ใบอนุญาตพิมพ์ A4 พร้อมกรอบ
